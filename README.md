# RestaurantBooking

A elegant restaurant website with online table reservation, built with vanilla HTML, CSS, and JavaScript — no frameworks, no dependencies.

## Live Demo

[View Site](https://supriaa.github.io/RestaurantBooking/)

## Features

- Responsive design with mobile hamburger navigation
- Animated scroll-reveal effects
- Auto-rotating testimonial carousel
- Table reservation form with client-side validation
- Booking confirmation message on successful submission

## Tech Stack

- HTML5
- CSS3 (custom properties, CSS transitions)
- Vanilla JavaScript (IntersectionObserver, form validation)
- Fonts: Cormorant Garamond + Montserrat (Google Fonts)

## Getting Started

No build step required. Open directly in a browser:

```bash
open index.html
```

Or serve locally:

```bash
python3 -m http.server 8080
# visit http://localhost:8080
```

## Project Structure

```
├── index.html      # All markup
├── styles.css      # All styling and design tokens
└── script.js       # Nav, carousel, scroll-reveal, form validation
```

## Deployment

Deployed automatically to GitHub Pages via GitHub Actions on every push to `main`.
